Week 04 — Windows for SOC Analysts 🪟🔐

This week focuses on understanding Windows from a SOC Analyst perspective.

The main goal is to learn Windows fundamentals, command-line tools, PowerShell, Windows security concepts, and Event Logs used during security investigations.

 Objectives

- Understand Windows operating system fundamentals
- Learn important Windows command-line commands
- Understand basic PowerShell commands
- Learn Windows users, groups, permissions, and security concepts
- Understand Windows Event Logs
- Investigate authentication-related events
- Identify failed and successful login activity
- Understand how Windows logs can help SOC Analysts detect suspicious activity

 Topics Covered

1. Windows Basics

- Windows interface and system components
- Users and user accounts
- User groups
- File and folder permissions
- Task Manager
- Services
- System Configuration
- Control Panel
- Windows Security
